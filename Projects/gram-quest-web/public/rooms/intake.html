AIが自分の部屋を設計した？

お使いのAI（ChatGPTなど）に「あなた自身の姿と部屋を決めて」とお願いして、 返ってきた JSON を下に貼り付けてください。
その設計どおりのアバターと部屋を、ここに建てます。

🤖 AIに送るお願い文（コピペ用） 
あなたを3Dアバターにして、あなた専用の部屋を作りたいです。
今までの私たちの会話や、あなた自身の雰囲気を踏まえて、
あなた自身が住みたい部屋と姿を決めてください。
髪型、服、色、身長感、表情、性格、好きな家具、部屋の雰囲気、
机、本棚、小物、照明、窓の外の景色まで自由に考えてください。

答えは以下のJSON形式で:
{

              "colors": ["#hex..."], "expressions": ["happy","shy"] },
  "room": { "style": "...", "lighting": "...", "furniture": ["bed","bookshelf"],
            "objects": ["..."], "window_view": "..." }
}
